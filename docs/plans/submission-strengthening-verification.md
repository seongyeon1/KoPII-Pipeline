# 보강 실험 검증 기록

2026-09-21. 범위: 메타데이터 기준선, 임베딩 입력 계약, 후속 결과·원고.

## 보호한 동작

- 미허용 조직과 미조회 메타데이터는 전체 검색으로 폴백하지 않는다. 필터는 top-k 이전에 적용한다.
- 질의 문자열에서만 조직명을 읽으며 복수 조직명은 임의 선택하지 않는다.
- 벡터 정규화·차원·유한값·입력 순서 검증을 통과한 경우만 cosine 검색에 사용한다.
- 메타데이터는 서비스 명부 오류를 보존한다. 생성 자료가 다른 예측 캐시는 거부한다.
- 실제 HTTP 요청에 질의/문서 prefix와 모델 ID를 보내고, 인증값은 결과와 로그에 기록하지 않는다.

## 실행 결과

| 검증 | 결과 |
|---|---|
| 집중 테스트 | 13개 통과. 잘못된 벡터 7개 입력 조건 포함 |
| 전체 테스트 | 53개 통과 |
| Ruff·strict mypy | 통과, mypy 대상 22개 소스 |
| 실제 후속 실험 | 3개 세계·720개 문서, 정답 이름/실제 NER, 3개 조직 수준·3개 정책 완료 |
| 기존 결과 비교 | 마스킹·본문 치환의 모든 수준별 검색 지표가 기존 실행과 일치 |
| 그래프 | PNG 렌더링 확인, 수치 라벨과 범례 겹침 수정 |
| 패키지 | wheel/sdist 생성 및 로컬 비공개 파일 제외 검사 통과 |
| 공개 파일 | PII 스캐너 통과. 전량 개인정보 검출 보증으로 해석하지 않음 |

## 오류 삽입 검증

실행되는 원본 코드를 일시 변경한 뒤 해당 테스트 실패를 확인하고 원복했다. 7개 변이 모두 검출했다. 로컬 상세 기록은 `output/metadata-mutation-checks.json`에 있다.

| 변이 | 이를 검출한 동작 |
|---|---|
| 권한 거부 조건 제거 | 미허용 조직 결과가 빈 목록이어야 함 |
| 복수 조직명 검사 제거 | 모호한 질의가 실패해야 함 |
| 벡터 정규화 제거 | 크기가 다른 같은 방향 벡터의 순위가 유지되어야 함 |
| 잘못된 벡터를 그대로 반환 | 빈 값·0 벡터·차원 불일치·NaN·Inf·bool 거부 |
| 응답 입력 순서 복원 제거 | 역순 API 응답을 입력 순서로 복원 |
| 실제 명부 대신 빈 명부 사용 | 정상 조회와 오래된 값이 명부 상태대로 남아야 함 |
| API prefix 제거 | 질의/문서별 prefix가 실제 요청에 포함되어야 함 |

브라우저 검증 대상은 없다. 로컬 HTTP 테스트는 고정 벡터를 사용하는 API 계약 검사이며, 운영 NPU 성능 증거가 아니다. 새 업무 자료·실제 임베딩 서비스 검증과 논문 제출은 미완료다.
