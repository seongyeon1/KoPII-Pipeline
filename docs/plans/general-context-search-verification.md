# 범용 API 검증 기록

2026-09-21. 패키지 버전 0.2.0.

| 검증 | 결과 |
|---|---|
| 전체 테스트 | 63개 통과 |
| 린트·포맷·strict mypy | 통과, 타입 검사 대상 28개 소스 |
| 원본 코드 오류 삽입 | 10개 변이 모두 검출 후 원복 |
| 기존 연구 결과 | 같은 3개 세계·720개 문서를 재실행한 모든 집계가 기존 metadata-study 결과와 정확히 일치 |
| CLI | 사용자 JSONL 준비·필터 검색·정답 기반 평가 실행 |
| 독립 wheel 설치 | 외부 런타임 의존성 없이 위 3개 명령 실행 성공 |
| 패키징·공개 자료 | wheel/sdist 생성, 비공개 파일 제외 검사와 PII 스캐너 통과 |

예제 질의의 만점 Recall은 두 개의 작은 가상 질문으로 동작을 확인한 결과이며 검색 성능 연구 결과가 아니다. 기존 실험 재실행은 벡터 검증 구현의 이동과 호환 import 경로가 기존 수치를 바꾸지 않았는지 확인한 회귀 검사다. 새 범용 BM25는 허용 후보 안에서 통계를 계산하므로 과거 연구 검색기의 대체 측정치로 취급하지 않는다.

## 검출한 오류 변이

1. 문서 접근 범위 조건 제거.
2. 중복 문서 ID 검사 제거.
3. Unicode 토큰화에서 비ASCII 문자 제거.
4. 실제 유형 마커 대신 일반 마커로 잘못 치환.
5. 조회 열의 모호성 조건 제거.
6. 임베딩 요청 prefix 제거.
7. 벡터 차원 오류를 0점으로 조용히 대체.
8. 기본 검색 응답에 메타데이터 노출.
9. 준비 단계에서 입력 메타데이터 주입 허용.
10. Recall 분모를 정답 수 대신 k로 계산.

각 변이를 실행 소스에 적용하고 대응 테스트 실패를 확인했다. 테스트 원문이나 문서만 바꾼 검증이 아니다. 로컬 기록은 `output/general-api-mutations.json`에 보존했다. 같은 이름의 테스트 파일을 계층별로 유지하기 위해 pytest의 importlib import 모드를 사용한다.

운영 NPU·cagent 배포·실제 사용자 인증·대규모 영속 인덱스·브라우저 검증은 이번 범위가 아니다. HTTP 계약 검증은 로컬 고정 벡터 서버로 수행했다. 실제 업무 자료와 모델 품질 수치를 새로 만들지 않았다.
