# 투고 전 보강 계획

2026-09-21. 기존 E2/E3 결과를 본 뒤 설계한 후속 비교이며 사전등록 연구가 아니다.

## 이번 실행

1. 기존 3개 가상 조직·720개 문서·고정 NER 예측을 재사용한다. 예측의 실행 ID와 생성 자료 해시를 검증하고 기존 결과는 덮어쓰지 않는다.
2. 이름 마스킹, 본문 조직 치환, 이름 마스킹+별도 조직 메타데이터 필터를 같은 BM25·질의·정답으로 비교한다. 메타데이터는 서비스 명부와 탐지 결과에서만 만들고 정답 인물의 조직으로 채우지 않는다.
3. 필터는 질의 문자열에서 조직명을 읽는다. 권한 범위를 명시적으로 받고 미허용·미조회 자료에 전체 검색 폴백을 하지 않는다. 이는 연구용 필터이며 제품의 인증·문서 ACL 구현이 아니다.
4. 공격자가 본문만 보는 조건과 반환 결과의 조직 필터를 아는 조건을 분리한다. 후자는 개인 추정 위험이 다시 커질 수 있다. 필터 관찰 조건의 분모는 해당 필터로 노출 가능한 문서이며 노출률도 함께 보고한다.
5. 실제 임베딩 API용 입력·실행·검증 경로를 준비한다. API 주소·모델·배포 버전이 확보되지 않으면 운영 NPU 결과를 만들지 않는다.
6. 측정값으로 논문과 결과 보고서를 갱신하고 투고 준비 자료를 만든다. 실제 업무 평가셋과 저자·소속은 사용자가 제공하기 전까지 미확정으로 둔다.

## 검증 계약

- 필터 입력에 relevance/정답 인물 데이터가 들어가지 않는다.
- 오래된 명부는 잘못된 메타데이터로 남고, 누락·동명이인 모호성을 정답으로 복구하지 않는다.
- 미허용 조직·빈 후보는 빈 결과를 반환한다.
- 임베딩 순서·개수·차원·유한값 검증 실패 시 평가를 중단한다.
- 본문만 보는 공격자는 숨겨진 메타데이터를 참조하지 않는다. 필터 관찰 공격자의 노출 범위와 분모를 공개한다.
- 기존 E3와 마스킹/본문 조직 치환 결과가 일치해야 한다. 시드별 결과와 평균·최솟값·최댓값을 보존한다.
- 집중 테스트, 오류 삽입 검증, 전체 테스트·린트·타입 검사·패키징·공개 파일 스캔을 수행한다.

## 남은 외부 입력

새 업무 평가셋은 원본 문서 가족별 분리와 주석 검수가 필요하다. 내부 문서·직원 명부는 공개 저장소로 복사하지 않는다. 운영 임베딩 엔드포인트·모델·전처리·배포 버전을 확인한 뒤 별도 승인된 평가 환경에서 실행한다. 합성 데이터 결과를 독립 업무 검증이나 실제 사용자 성능으로 보고하지 않는다.
