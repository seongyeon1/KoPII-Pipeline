# 범용 패키지 검증 기록

검증일: 2026-09-21. 대상: `kopii-pipeline` 0.1.0 초기 공개 구현.

## 자동 검증

- Python 3.11 환경에서 pytest **30개 통과**.
- 새 패키지·테스트의 Ruff lint/format 검사 통과.
- 패키지 20개 Python 모듈의 strict mypy 검사 통과.
- 실제 실행문을 일시적으로 변경한 **27개 표적 변이 모두 탐지**. 변경한 문장은 매 실행 후 복원했습니다. 전수 mutation coverage 점수는 아닙니다.
- 저장소 외부 작업 디렉터리의 별도 가상환경에 wheel만 설치하고, 신경망 의존성 없이 가상 조직 예제 실행 성공.
- wheel·소스 배포 파일 생성 및 내부 문서·로컬 보고서·데이터·실행 산출물 제외 검사 통과. 중첩 `.gitignore`만으로 배포를 통제하지 않고 sdist의 포함 목록을 명시했습니다.

보호한 동작은 탐지 오류 전파, 조회 오류 대체 처리, 팀이 다른 동명이인, Unicode 원문·출력 위치, 겹침 구간 전체 보호, 문서별 가명 일관성, 결과 JSON과 모델 진행 로그의 분리, 평가 결과 혼용 방지입니다.

## 실제 가중치 실행

기존 모델 캐시와 Apple Silicon MPS 환경에서 실행했습니다. torch 2.14.0 / transformers 4.57.6 / gliner 0.2.29 / gliner2 2.0.0 환경이며, 후보 revision은 `configs/eval-*.json`에 명시한 버전입니다.

| 확인 항목 | 결과 |
|---|---|
| 한국어 RoBERTa 추론 | 예제 개인정보 탐지 및 반환 위치 유효성 확인 |
| RoBERTa 장문 | 반복된 일반 문장 뒤에 위치한 개인정보 탐지 확인 |
| NVIDIA GLiNER 추론 | 예제 실행·위치 유효성·CLI JSON 출력 확인 |
| Fastino GLiNER2 추론 | 예제 실행·위치 유효성·CLI JSON 출력 확인 |
| 새 학습 기준선 | 학습 fixture 16건에서 optimizer 1 step 실행, 모델·토크나이저 저장, dev 4건 추론·채점 완료 |

새 학습은 실행 검증을 위해 축소한 조건이며 학습 성능을 입증하지 않습니다. 기존 배포 모델을 덮어쓰거나 공개 모델 가중치를 교체하지 않았습니다. GLiNER2는 실행 환경에서 SDPA 미지원 경고 후 eager attention으로 실행됐습니다.

## 연구 실행

합성 fixture의 동일 시드 재현, 템플릿·원천 그룹 분리, 분할 검사, 규칙 모델 평가와 그룹 부트스트랩을 실행했습니다. 같은 실행의 이어쓰기는 기존 예측을 유지하고, 설정·데이터가 변경된 이어쓰기는 거부하는 것을 확인했습니다.

## 범위와 미검증 항목

위 초기 기록은 소프트웨어 동작 검증입니다. 이후 같은 날짜에 수행한 설정·정책 실험은 아래 후속 검증과 [연구 보고서](../../research/RESULTS.md)로 구분합니다. 실제 업무 정확도와 운영 GPU HTTP 성능은 측정하지 않았습니다.

GitHub Actions에는 Python 3.11/3.12의 패키지·오프라인 예제·fixture 검증을 정의했습니다. 가중치를 사용하는 추론·학습은 기본 CI에서 수행하지 않습니다.

## 한국어 설정·조직 실험 후속 검증

- 기본 단위 테스트 **40개** 통과, Ruff lint/format 및 21개 모듈 strict mypy 통과.
- 새 경계/배치/공격 채점의 **7개 표적 변이 모두 탐지**. 임시 소스 복사본에서 실행하여 실제 추론 중인 파일은 변경하지 않았습니다. 역할 필터를 제거하는 변이를 처음 놓쳐 반례를 추가한 뒤 다시 확인했습니다. 전수 mutation coverage가 아닙니다.
- 두 GLiNER 후보에서 각각 개발 설정 30개와 직접 임계값 추론 일치 144건 검사. 개발 선택 파일 저장 후 전체 테스트 재평가.
- 가상 세계 3개·720문서에서 실제 RoBERTa 추론, 6개 정책 × 2개 구간 조건의 검색·공격 측정 완료.
- 업무참조 문자열 637개에 대한 PASSPORT_NUM 오인을 가상 원문과 대조해 확인. 정답 이름만 주석한 조건에서 다른 유형 전체를 오탐으로 취급하지 않았습니다.
- [실행 노트북](../../research/01-Study-Results.ipynb)과 집계 기반 그림 제공. 원문/문서별 예측은 공개 결과에서 제외.

단위 테스트는 문서 간 위치 분리, 음절 경계의 Unicode 위치 보존, 빈/잘못된 후보 집합의 공격 실패 처리, 소속·직급·과제별 후보 축소와 실제 치환 결과의 검색/공격 입력을 검사합니다. 신경망 지표 및 가상 조직 결과의 적용 범위는 [측정 보고서](../../research/RESULTS.md)에 기술했습니다.

Fastino 전체 평가 과정에서 발견한 자동 마침표 추가를 원문 좌표로 되돌리는 회귀 검사를 추가했습니다. 추가 문자만 반환된 경우·원래 있던 문장부호·임의 범위 초과·표면 불일치를 구분합니다. 수정 후 Fastino는 처음부터 재평가했고, 조직 실험도 재실행해 모든 세계의 집계가 동일함을 확인했습니다. NVIDIA는 변경되지 않은 분기와 공통 소스를 검사하여 완료된 원래 실행의 출처를 보존했습니다.

공개 결과의 비율은 소수점 6자리로 표기하고 SVG는 텍스트 레이블을 유지했습니다. 개인정보 패턴 검사는 집계 파일 전체를 예외 처리하지 않습니다. SHA-256 내부의 우연한 숫자 패턴은 해당 값이 저장소 내부 Python 소스의 실제 해시와 일치할 때만 제외하며, 검증되지 않은 값·파일명·다른 문자열은 계속 검사합니다. 변경된 파일의 해시를 신뢰하지 않는 반례와 일반 전화번호 탐지를 테스트했습니다.
