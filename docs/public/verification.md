# 범용 패키지 검증 기록

검증일: 2026-09-21. 대상: `kopii-pipeline` 0.1.0 초기 공개 구현.

## 자동 검증

- Python 3.11 환경에서 pytest **30개 통과**.
- 새 패키지·테스트의 Ruff lint/format 검사 통과.
- 패키지 20개 Python 모듈의 strict mypy 검사 통과.
- 실제 실행문을 일시적으로 변경한 **27개 표적 변이 모두 탐지**. 변경한 문장은 매 실행 후 복원했습니다. 전수 mutation coverage 점수는 아닙니다.
- 저장소 외부 작업 디렉터리의 별도 가상환경에 wheel만 설치하고, 신경망 의존성 없이 가상 조직 예제 실행 성공.
- wheel·소스 배포 파일 생성 및 내부 문서·로컬 보고서·데이터·실행 산출물 제외 검사 통과. 중첩 `.gitignore`만으로 배포를 통제하지 않고 sdist의 포함 목록을 명시했습니다.

보호한 동작은 탐지 오류 전파, 조회 오류 대체 처리, 팀이 다른 동명이인, Unicode 원문·출력 위치, 겹침 구간 전체 보호, 문서별 가명 일관성, 결과 JSON과 모델 진행 로그의 분리, 평가 결과 혼용 방지입니다.

## 실제 가중치 실행

기존 모델 캐시와 Apple Silicon MPS 환경에서 실행했습니다. torch 2.14.0 / transformers 4.57.6 / gliner 0.2.29 / gliner2 2.0.0 환경이며, 후보 revision은 `configs/eval-*.json`에 명시한 버전입니다.

| 확인 항목 | 결과 |
|---|---|
| 한국어 RoBERTa 추론 | 예제 개인정보 탐지 및 반환 위치 유효성 확인 |
| RoBERTa 장문 | 반복된 일반 문장 뒤에 위치한 개인정보 탐지 확인 |
| NVIDIA GLiNER 추론 | 예제 실행·위치 유효성·CLI JSON 출력 확인 |
| Fastino GLiNER2 추론 | 예제 실행·위치 유효성·CLI JSON 출력 확인 |
| 새 학습 기준선 | 학습 fixture 16건에서 optimizer 1 step 실행, 모델·토크나이저 저장, dev 4건 추론·채점 완료 |

새 학습은 실행 검증을 위해 축소한 조건이며 학습 성능을 입증하지 않습니다. 기존 배포 모델을 덮어쓰거나 공개 모델 가중치를 교체하지 않았습니다. GLiNER2는 실행 환경에서 SDPA 미지원 경고 후 eager attention으로 실행됐습니다.

## 연구 실행

합성 fixture의 동일 시드 재현, 템플릿·원천 그룹 분리, 분할 검사, 규칙 모델 평가와 그룹 부트스트랩을 실행했습니다. 같은 실행의 이어쓰기는 기존 예측을 유지하고, 설정·데이터가 변경된 이어쓰기는 거부하는 것을 확인했습니다.

## 범위와 미검증 항목

이 기록은 소프트웨어 동작 검증입니다. 기존 2,586건 비교를 새 패키지로 다시 실행한 결과, 조정된 GLiNER 성능, 실제 업무 정확도, 조직 범주화의 활용성·개인 추정 위험, 운영 GPU HTTP 성능은 포함하지 않습니다. 추가 실험은 [연구 계획](../../research/PLAN.md)에 남겼습니다.

GitHub Actions에는 Python 3.11/3.12의 패키지·오프라인 예제·fixture 검증을 정의했습니다. 가중치를 사용하는 추론·학습은 기본 CI에서 수행하지 않습니다.
