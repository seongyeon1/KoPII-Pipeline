# KoPII-Pipeline

**한국어 개인정보를 지우지 않고 범주화하는 비식별 파이프라인.**

> A Korean PII pipeline that *generalizes* instead of masking — it walks each
> identifier up an abstraction hierarchy so the sentence keeps its meaning.
> Design docs are in Korean.

---

## 왜 마스킹이 아닌가

대부분의 비식별 도구는 개인정보를 `[MASK]`로 덮습니다. 안전하지만 문장이 죽습니다.

```
원문      김민수 부장(사번 2304118)이 강남 사옥에서 계약을 체결했다.
마스킹    [MASK] [MASK](사번 [MASK])이 [MASK]에서 계약을 체결했다.
범주화    [플랫폼개발팀 부장]([정규직])이 서울시 강남구에서 계약을 체결했다.
```

세 번째 줄은 **누구인지는 알 수 없지만 무슨 일이 있었는지는 남습니다.** 외부 LLM에
보내도 응답 품질이 유지되고, RAG 인덱스에 넣어도 검색이 됩니다.

KoPII는 PII 타입마다 **일반화 계층**을 정의하고, 정책이 "어느 층까지 올릴지"를 정합니다.

```
사번 2304118                          주민번호 900101-1234567
 L0  2304118          (원본)            L1  [1990년생 남성]
 L1  [플랫폼개발팀 사원] (팀)             L2  [30대 남성]
 L2  [개발본부 사원]     (본부)           L3  [주민번호]
 L4  [정규직]          (고용 형태)
 L5  [사번]            (완전억제)
```

레벨을 올릴수록 재식별 위험이 내려가고 의미도 같이 내려갑니다. **그 트레이드오프를
측정해서 레벨을 고르는 것**이 이 프로젝트의 핵심입니다.

## 설계의 특징

- **fail-closed** — 조직 지식이 없으면 더 추상적인 레벨로 **올라갑니다.** 어떤 경우에도
  원본 노출 쪽으로 떨어지지 않습니다.
- **일관성과 가역성의 분리** — 같은 사람이 항상 같은 값이 되는 것은 HMAC으로 계산하므로
  저장소가 필요 없습니다. 복원용 vault는 외부 LLM 경로에만 존재합니다.
- **특정 조직에 종속되지 않음** — 사번 포맷을 값 리스트에서 자동 추론하고, 한국 고유
  지식은 로케일 팩으로 분리합니다. 조직도가 없어도 동작하고, 채워질수록 좋아집니다.
- **한국어 조사 교정** — 치환으로 받침이 바뀌면 뒤따르는 조사가 틀립니다
  (`박정호은` → `박정호는`). 이걸 처리하지 않으면 문장이 비문이 됩니다.
- **외부 데이터 없이 실행** — 공개 한국어 PII 코퍼스가 사실상 없으므로 가상 조직을
  통째로 만드는 합성 생성기를 내장합니다.

## 현재 상태

**설계 단계입니다. 아직 동작하는 코드가 없습니다.**

전체 설계는 [`docs/design/2026-08-28-pii-anonymize-design.md`](docs/design/2026-08-28-pii-anonymize-design.md)에
있습니다 — 아키텍처, 계층 DSL, 일관성·가역성 메커니즘, 평가 방법론, 합성 데이터
생성기까지 다룹니다.

### 지금 돌려볼 수 있는 것

합성 코퍼스 생성기가 동작합니다. 외부 데이터도 네트워크도 필요 없습니다.

```bash
pip install -e ".[dev]"

# 가상 조직 2,000명 + 문서 20,000건 생성 (data/ 아래, gitignore됨)
python -m kopii.synth --config configs/synth.yaml

# 생성물 무결성 검사
python -m kopii.synth.validate --dir data/
```

산출물은 세 개입니다.

| 파일 | 내용 |
|---|---|
| `population.jsonl` | 구성원 — 이름·닉네임·사번·소속·직급·연락처 |
| `corpus.jsonl` | 문서 — 본문과 정답 PII span (`entity_key` 포함) |
| `manifest.json` | 시드·설정·개수, 그리고 사번 채번의 **정답 메타데이터** |

현재 생성되는 코퍼스에는 `NAME`, `NICKNAME`, `EMPLOYEE_ID`, `RRN`, `PHONE`,
`EMAIL`, `ADDRESS` 타입만 실제로 심겨 있습니다. `ACCOUNT`, `CARD`, `DOB`,
`URL`, `USERNAME`은 라벨 스키마에는 정의돼 있지만 아직 어떤 템플릿도 심지
않으므로, 이 코퍼스만 보고 해당 타입까지 커버된다고 가정하지 마세요.

`manifest.json`의 채번 정답은 나중에 ID 스키마 추론기를 채점하는 데 쓰입니다.
시드가 같으면 언제든 같은 코퍼스가 재현되므로 파일을 공유할 필요가 없습니다.

### 구현 순서

합성 코퍼스가 모든 측정을 떠받치고, 측정이 정책 기본값을 결정하므로 순서가 강제됩니다.

| # | 모듈 | 내용 |
|---|---|---|
| ① | `synth/` | 가상 조직 + 문서 생성 — 측정 대상이 없으면 아무것도 잴 수 없다 |
| ② | `detect/` | 규칙 기반 탐지 + ID 스키마 추론기 |
| ③ | `identity/` | 동일인 연결 + 결정적 가명 |
| ④ | `hierarchy/` | 일반화 계층 + 프리미티브 |
| ⑤ | `policy/` `render/` `josa/` | 치환 경로 완성 |
| ⑥ | `evaluation/` | 위험·유틸리티 지표 + 레벨 스윕 |
| ⑦ | `vault/` `restore/` | 외부 LLM 가역 경로 |

## 보안 원칙

이 레포에는 **실 개인정보와 사내 조직 지식이 들어가지 않습니다.**

- 조직도·`hr_directory`·실제 사번 포맷·실문서는 커밋 금지. 설정으로만 주입합니다.
- 가명 HMAC 키와 vault 키는 환경변수로만 받고, **기본값을 제공하지 않습니다.**
  공개 레포에 예시 키가 박히면 그 키로 만든 가명은 전부 역산 가능합니다.
- PR마다 [`scripts/pii_scan.py`](scripts/pii_scan.py)가 변경 파일을 훑습니다.
  체크섬을 통과한 주민번호·카드·사업자번호와 자리표시가 아닌 전화번호를 잡아 CI를
  실패시킵니다.

```bash
python scripts/pii_scan.py .
```
