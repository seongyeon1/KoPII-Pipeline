# 투고 준비 상태

2026-09-21. **arXiv 업로드·학회 제출은 아직 하지 않았다.** 원고와 실험 자료를 준비하는 단계다. 저자·소속·최종 주장 범위는 미확정이다.

## 원고의 중심 주장

가제: **Beyond PII Detection: Retrieval Utility and Identity-Inference Risk in Korean Enterprise Documents**

1. 한국어 설정 탐색에서 전체 exact F1의 개선과 이름 보호 성능은 다른 방향으로 움직일 수 있다.
2. 조직 범주화의 검색 효용은 본문에 조직명을 직접 노출하는 방법뿐 아니라 별도 메타데이터 필터에서도 얻을 수 있다.
3. 본문만 보는 공격자와 검색 필터를 관찰하는 공격자는 구분해야 한다. 메타데이터 분리만으로 후자의 개인 추정 위험이 사라지지는 않는다.

두 번째·세 번째 주장은 기존 합성 과제에서 측정한 조건부 결과다. 전체 F1, 검색 Recall@5, 개인 추정 성공률을 하나의 “보호 성능”으로 합치지 않는다. 새로운 모델 구조나 수학적 익명성 보장을 기여로 주장하지 않는다.

## 제출 경로

| 경로 | 준비 방향 | 확인된 일정·상태 |
|---|---|---|
| arXiv | 출처·한계·저자 정보가 정리된 영문 preprint와 코드 연결 | [제출 안내](https://info.arxiv.org/help/submit/index.html). 동료심사 게재와 구분 |
| PrivateNLP 차기 회차 | 개인정보 보호 평가와 위협 모델 중심 | [2026 공식 페이지](https://sites.google.com/view/privatenlp2026)의 회차는 종료. 2027 일정 미확인 |
| NAACL 2027 Industry Track | 실제 배포 경험과 운영 자료 검증 보강 | [공식 CFP](https://2027.naacl.org/calls/industry_track/) 일정표는 2026-10-31 AoE, 상단은 2027-10-31로 상충. 확정 마감으로 취급하지 않음 |

NAACL 공식 CFP는 본문 최대 6쪽, 익명 심사, 별도 직접 제출(ARR 미사용)을 안내한다. arXiv 공개를 허용하지만 심사본에는 비익명 GitHub 링크를 넣지 않도록 규정한다. 동일 원고를 여러 심사 학회에 동시에 제출하는 경로로 계획하지 않는다. 실제 제출 시 최신 CFP를 다시 확인한다.

## 6쪽 원고 구성안

| 내용 | 대략 분량 | 핵심 자료 |
|---|---:|---|
| 초록·문제·기여 | 0.75쪽 | 탐지 지표와 실제 정보 노출의 차이 |
| 관련 연구·과제·위협 모델 | 1쪽 | 한국어 탐지, 텍스트 비식별화, 본문/검색 관찰 범위 |
| 시스템·자료·실험 설계 | 1.25쪽 | 탐지–조직 조회–정책 분리, split·설정 선택·분모 |
| 탐지 설정 결과 | 0.75쪽 | E2 F1·이름 recall·오탐, 비대칭 학습의 한계 |
| 검색·개인 추정 결과 | 1.5쪽 | 본문 치환 vs 메타데이터 필터, 관찰 조건별 위험 |
| 논의 | 0.75쪽 | 운영 적용 함의와 실패 조건 |

이 배분은 작성 계획이다. 현재 Markdown 초안이 6쪽을 충족하거나 공식 템플릿 검증을 통과했다는 뜻은 아니다. 상세 설정표·전량 집계·과거 도입 검토 표는 부록 후보로 둔다.

## 완료 및 남은 작업

| 항목 | 상태 |
|---|---|
| 기존 후보 한국어 설정 탐색·그룹 평가 | 완료, 과거 테스트 재평가로 한정 |
| 범주화와 마스킹 비교 | 완료, 가상 조직·BM25에 한정 |
| 별도 메타데이터 검색 기준선 | 완료, 같은 720개 가상 문서의 후속 비교 |
| 검색 필터가 알려지는 공격 조건 | 완료, 명부 조회 성공 636개 문서의 조건부 관찰 모델 |
| 운영 임베딩 실행 경로 | 구현·로컬 HTTP 계약 검증, 실제 NPU 미실행 |
| 새 업무 평가셋 | 미확보, 원천 그룹 분리·주석 검수 필요 |
| 같은 자료 후보 추가 학습·합성 효과 ablation | 미실시. 주장 범위를 확대하려면 수행 필요 |
| 관련 연구·원천 데이터 이용 조건 | 추가 확인 필요 |
| 저자·소속·연구비·공개 권한 | 미확정 |
| 공식 템플릿 조판·최종 원고 검토 | 미완료 |

후속 실행은 [평가 계약과 명령](../research/METADATA_STUDY.md)을 따른다. 실제 자료가 확보되지 않으면 합성 통제 실험 중심으로 원고 범위를 확정하고 운영 성능 주장을 넣지 않는다. 이 경우에도 원천 인용·저자 검토·템플릿 작업은 남는다.
