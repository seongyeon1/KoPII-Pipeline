# data/

**이 디렉터리에는 데이터 파일을 커밋하지 않는다.** 이 README만 버전 관리된다.

- **합성 코퍼스** — `python -m kopii.synth` 로 생성한다. 시드가 고정돼 있어 누구나
  같은 코퍼스를 재현할 수 있으므로 파일을 공유할 이유가 없다.
- **공개 데이터셋** — AI Hub 등은 재배포가 제한된다. 다운로드 스크립트와 체크섬만
  버전 관리하고 데이터 자체는 각자 내려받는다.
- **실문서·조직 지식** — 반입 금지. `hr_directory`나 실제 사번 목록이 필요하면
  이 레포 밖에 두고 경로로만 참조한다.
