# KoPII 연구 계획과 증거 구분

작성일: 2026-09-21. 문서 상태: E2 설정 탐색·E3 가상 조직 실험 완료, E1·외부 검증 미완료.

## 연구 질문

한국어 업무 문서에서 개인정보를 탐지하고 조직정보를 참조해 범주화할 때, 탐지 누락·과도한 치환·업무정보 활용성·개인 추정 위험이 어떻게 달라지는가?

가설을 결과로 쓰지 않습니다. 일반화 가능한 인터페이스의 존재는 다국어 성능이나 개인정보 보호 보증을 뜻하지 않습니다.

## E1. 데이터 합성 효과

같은 기반 모델·학습 예산·선택 기준에서 공개 자료만, 공개+업무 합성, 공개+업무 합성+hard negatives를 비교합니다. 최초 비교와 별개로 손실 함수(Focal/CE), 입력 절단/overflow의 영향을 분리합니다. 코드의 CE 기준선을 기존 Focal 실험으로 기술하지 않습니다.

최소 3개 사전 지정 시드로 실행하고 평균·편차를 기록합니다. 데이터 양 효과와 구성 효과를 구분할 수 있도록 가능하면 레코드 수 또는 토큰 예산을 맞춘 보조 실험을 둡니다. 최적화 설정·탐색 예산은 결과를 보기 전에 파일로 고정합니다.

템플릿·원본 대화·문서 가족 단위로 분리하고 변형 문장과 이름 치환본이 다른 split에 섞이지 않게 합니다. 기존 100k 자료의 생성 경로·재배포 조건·원천 그룹 대응을 확인한 후 연구 데이터 버전을 확정합니다. 새 fixture를 확대 복제하는 것으로 이를 대체하지 않습니다.

## E2. 초기 도입 후보의 한국어 적용

NVIDIA GLiNER-PII, Fastino GLiNER2-PII는 처음 도입을 검토한 후보입니다. 낮은 초기 점수만을 일반적 우열 주장에 사용하지 않습니다.

| 조건 | 통제와 목적 |
|---|---|
| 최초 설정 | 과거 코드·revision으로 도입 검토 결과 재현 |
| 한국어 유형 표현·임계값 조정 | 검증셋만 사용, 후보별 탐색 예산 기록 |
| 한국어 단어/문자 경계 변경 | 다른 설정을 고정해 경계 처리 효과 분리 |
| 동일 한국어 자료 추가 학습 | 지원 모델과 예산 명시, 미실시 모델은 그 한계를 유지 |

exact typed span P/R/F1/F5, 유형별 support·recall, 문자 보호 precision/recall, 음성 문서 오탐률을 함께 보고합니다. 범주에 정답이 0개라면 해당 유형의 우수성을 주장하지 않습니다. 문서 전체 coverage와 잘림 여부를 점검하고 모델별 최대 길이·창 전략을 표에 명시합니다.

## E3. 조직 범주화의 효과

비교 정책은 전체 마스킹, 문서 단위 가명, 팀, 본부, 센터입니다. 같은 정답 개인정보 구간을 입력하는 실험으로 정책 효과를 먼저 비교하고 실제 탐지 결과를 사용하는 실험으로 누적 오류를 확인합니다.

첫 업무 과제는 담당 조직 질의응답으로 제한합니다. 원문, 질문, 정답 조직, 문서·인물 연결, 조직 수준을 별도 주석합니다. 정책마다 동일한 검색기·질의·응답 모델·프롬프트를 사용하고 정답률과 검색 Recall@k를 측정합니다. 평가 질문과 정답이 합성기 템플릿에서 기계적으로 복사되어 사소한 문제가 되지 않는지 검토합니다.

개인 추정 위협 모델을 사전 고정합니다. 공격자가 조직 명부를 갖는 경우와 갖지 않는 경우, 직급·업무·시점을 아는 경우를 구분합니다. 후보 집합에서 top-1 개인 추정 성공률과 공격 실패율을 보고하고 원문·마스킹 기준선을 둡니다. 작은 팀·겸직·동명이인·조직 개편·미조회·오래된 조직정보를 별도 분석합니다. 후보 집합 크기를 실제 익명성 보장으로 해석하지 않습니다.

가상 조직의 실험은 재현 가능한 통제 실험입니다. 실제 조직 위험이나 실제 검색 품질의 대체 증거가 아닙니다. 실제 업무 표본을 사용할 수 없다면 논문의 주장 범위도 가상 조직 실험으로 제한합니다.

## 평가 오염 방지

기존 KDPII 결과는 이미 오류 분석에 사용되었습니다. 이후 발견한 오류를 반영한 설정의 최종 독립 테스트로 그대로 재사용하지 않습니다. 새 개발셋과 사용하지 않은 최종 평가셋을 준비하거나, 외부 검증이 불가능한 경우 그 사실을 명시합니다.

파생 단문과 원본 대화는 같은 그룹으로 부트스트랩합니다. 그룹별 분할을 먼저 고정하고 모든 모델에 같은 자료를 적용합니다. 튜닝 로그, 실패 실행, 데이터 제외 기준도 보존합니다. 논문 표에는 실행 ID와 완료 레코드 수를 연결하고 부분 실행의 점수를 전량 점수로 표시하지 않습니다.

## 순서와 완료 기준

1. 연구 기반 공개: 설치·예제·테스트·모델 추론·학습 저장 확인, 초기 결과 보존.
2. 데이터 버전 확정: 원천·이용 조건·그룹·범주·누수 검사와 새 평가셋 확보.
3. E1/E2: 사전 지정 설정으로 수행하고 원인별 기여 분석.
4. E3: 활용성·개인 추정 위험을 같은 정책 축으로 측정.
5. 논문 마무리: 실제 결과로 표·그림 작성, 한계·윤리·재현성 검토.

현재 버전은 연구 기반과 E2 설정 탐색·기존 테스트 재평가, E3 가상 조직 통제 실험을 제공합니다. 실행 전 고정한 설정, 전체 집계와 제한은 [결과 보고서](RESULTS.md)에 연결했습니다. E1, 같은 자료 추가 학습, 미사용 실제 업무 평가셋과 운영 NPU 검색/더 강한 공격자 검증은 남아 있습니다. 미측정 항목은 논문 결론에 포함하지 않습니다.
